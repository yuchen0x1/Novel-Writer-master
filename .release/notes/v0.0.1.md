# 0.0.1

## Novel-Writer-master 首个独立版本

- 产品、窗口、安装程序和快捷方式统一使用 Novel-Writer-master 名称及新图标。
- 重新拍摄中英文实际界面，替换项目首页的旧品牌宣传图与截图。
- 更新源、下载入口和发布资产统一指向 `yuchen0x1/Novel-Writer-master`。
- 保留设定、架构、章节蓝图、写作、审稿、修稿、定稿、知识库、导入导出与备份能力。
- 修复 Electron 42 的 SQLite 原生依赖编译兼容问题。

版本号从 0.0.1 开始。旧 1.x 客户端需要手动安装一次新版本，后续按 0.0.x 版本序列更新；不强制自动降级。作品与设置目录继续沿用。

Windows 安装包未代码签名；macOS 安装包使用 ad-hoc 签名，未经 Developer ID 签名和 Apple 公证。请仅从此仓库下载，并核对 SHA256SUMS.txt。

## First independent Novel-Writer-master release

- Consistent application name, icon, window titles, installer, and shortcuts.
- Fresh Chinese and English screenshots captured from the current desktop app.
- Downloads and update metadata point to `yuchen0x1/Novel-Writer-master`.
- Existing writing, planning, review, revision, knowledge, import/export, and backup features remain available.
- SQLite native dependency updated for Electron 42 compatibility.

The new version sequence starts at 0.0.1. Install this version manually once when switching from the previous 1.x series; automatic downgrades are not forced. Existing books and settings retain their storage locations.

Windows packages are not code-signed. macOS packages use ad-hoc signing and are not Developer ID signed or notarized. Download only from this repository and verify SHA256SUMS.txt.
