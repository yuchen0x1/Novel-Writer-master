# 1.10.0

## 中文

### 新增

- 产品显示名称、启动页、关于页与 Windows/macOS 图标统一更新为 **Novel Writer master**。为兼容旧安装，稳定 appId、应用数据目录和自动更新资产文件名保持不变，已有作品和设置继续沿用。
- 新写入的模型 API Key 使用系统安全密钥库加密保存。旧版明文 Key 仍可读取，并会在再次保存模型配置时加密；Linux 需要 GNOME Keyring 或 KWallet。系统密钥库不可用时会给出明确提示，且不会把新 Key 退回为明文保存。

### 改进

- 顶栏保存状态和失败重试按当前作品会话租约隔离。关闭后重开同一路径的作品，不会再沿用上一会话的保存状态或重试入口。
- 硬件加速切换后，设置页会持续说明需要重启应用才能生效。

### 修复

- 修复点击“稍后提醒”后更新提示不能立即关闭的问题。

### 发布说明

- 沿用数据库 schema 9，无需迁移作品数据结构。
- Windows x64 安装包未签名；macOS 安装包为 ad-hoc 签名且未公证。请只从本项目官方 GitHub Release 下载。

## English

### Added

- Updated the product name, launch screen, About page, and Windows/macOS icons to **Novel Writer master**. The stable app ID, app-data directory, and auto-update asset names remain unchanged for compatibility, so existing books and settings continue to be used.
- Newly saved model API keys are encrypted with the OS key store. Legacy plaintext keys remain readable and are encrypted the next time model settings are saved. Linux requires GNOME Keyring or KWallet; if no secure system key store is available, the app explains the issue and does not save a new key in plaintext.

### Improved

- Top-bar save status and failed-save retries are isolated to the active project-session lease. Closing and reopening a project at the same path no longer carries over stale status or retry actions.
- The hardware-acceleration setting now keeps the restart-required notice visible after a change.

### Fixed

- Fixed update notifications not closing immediately after choosing “Remind me later”.

### Release notes

- Database schema remains at version 9; no project data migration is required.
- The Windows x64 installer is unsigned. macOS installers are ad-hoc signed and not notarized. Download only from this project's official GitHub Release.
