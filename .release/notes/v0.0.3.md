# 0.0.3

## 版本概述

这是一个稳定性维护版本，修复 2026-11-19 全项目审计中发现的恢复、备份与写作流程问题，并改进 Windows 路径约束下的归档与备份稳健性。界面语言、作品正文与写作语言设置行为保持不变。

## 修复

- 作品恢复前验证 Windows 路径约束；修复预约标记创建失败时的残留，中断恢复保留受控预约以支持重试。
- 云备份登录与当前作品配置绑定：登录态与当前项目的 profile 对齐，避免错绑到其他作品。
- 角色名单解析拒绝截断容器的嵌套片段，修复静默截断导致的角色丢失。
- 后处理守卫区分状态缺失与读取错误，工作流中断不再被误判为完成。
- 草稿快照的插入与裁剪改为同一事务；WebDAV 连接验证拒绝非 DAV 响应，并返回上传后的同级备份分支。
- 已知限制：迁移进程被强制终止或断电后，临时数据库快照仍可能残留，需要人工清理。

## 平台与安装

- Windows x64 提供 NSIS 安装程序及更新元数据。安装程序未做 Authenticode 签名。
- macOS Intel 和 Apple Silicon 提供各自的 DMG。应用使用 ad-hoc 签名，未完成 Apple Developer ID 签名和公证。
- 作品、模型配置和写作语言继续沿用。更新前可在工作台导出作品备份。
- 助手聊天入口保持隐藏；写作、审稿、修稿流程不受影响。

## Release overview

This is a stability maintenance release. It fixes the restore, backup and writing-flow issues found in the 2026-11-19 project audit, and hardens archives and backups under Windows path constraints. Interface language, book content and writing-language settings are unchanged.

## Fixes

- Project restore validates Windows path constraints before extraction and removes owned residue when reservation-marker creation fails. Interrupted restores retain controlled reservations for retry.
- Cloud backup login is aligned with the current project profile instead of being bound to a different book.
- Character roster parsing rejects nested fragments of truncated containers, fixing silent truncation and lost characters.
- Post-processing guards distinguish missing state from read errors, so an interrupted workflow is no longer treated as complete.
- Draft snapshot insertion and pruning now share one transaction. WebDAV connection checks reject non-DAV responses, and uploads report sibling backup branches.
- Known limitation: a forced termination or power loss during migration may leave temporary database snapshots that require manual cleanup.

## Platforms and installation

- Windows x64 uses an NSIS installer. The installer has no Authenticode signature.
- macOS Intel and Apple Silicon have separate DMG files. The app uses ad-hoc signing without Developer ID signing or notarization.
- Books, model settings, and writing languages carry forward. You can export a project backup before updating.
- The assistant chat entry stays hidden; writing, review, and revision flows are unaffected.
