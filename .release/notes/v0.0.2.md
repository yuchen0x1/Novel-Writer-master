# 0.0.2

## 版本概述

首次启动时，工作台按系统语言选择中文或 English。你可以在设置中切换并保存界面语言。macOS 更新提醒会指引你去官方下载页选择安装包。

## 平台与安装

- Windows x64 提供 NSIS 安装程序及更新元数据。安装程序未做 Authenticode 签名。
- macOS Intel 和 Apple Silicon 提供各自的 DMG。应用使用 ad-hoc 签名，未完成 Apple Developer ID 签名和公证。
- 作品、模型配置和写作语言继续沿用。更新前可在工作台导出作品备份。
- 助手聊天入口保持隐藏；写作、审稿、修稿流程不受影响。

## Release overview

On first launch, the workspace uses your system language to choose Chinese or English. You can change and save your interface language in Settings. On macOS, the update dialog opens the official download page so you can choose the matching installer.

## Platforms and installation

- Windows x64 uses an NSIS installer. The installer has no Authenticode signature.
- macOS Intel and Apple Silicon have separate DMG files. The app uses ad-hoc signing without Developer ID signing or notarization.
- Books, model settings, and writing languages carry forward. You can export a project backup before updating.
- The assistant chat entry stays hidden; writing, review, and revision flows are unaffected.
