# 1.9.0

## 中文

### 新增

- 草稿自动快照：每次保存或 AI 生成落稿时自动记录本章草稿快照（每稿保留最近 30 份，内容相同不重复记录），版本菜单里可直接按时间、字数与来源（生成时/保存时）查看。
- 快照恢复为新草稿：从版本菜单选一份快照即可新建一稿恢复，不覆盖、不删除任何已有稿；审稿修稿合并进正文的时点同样会留下快照。
- 顶栏保存状态：保存中、已保存（悬停显示上次保存时间）、未保存、保存失败一目了然；保存失败时可在顶栏一键重试最近一次失败的保存。状态按作品归属，切换作品不会显示上一部作品的保存信息。

### 改进

- 快照菜单在读取失败或还没有快照时给出明确说明；恢复快照不再预读版本号，新稿版本号由数据库事务原子分配，避免版本被并发占走后提示错版本。

### 修复

- 修复已登记的 schema 8 项目无法原地升级到 schema 9 的问题：升级入口现在接受全部已登记的历史版本，先校验 schema 指纹与作者数据，再在事务内迁移。
- 修复版本切换器在失效项目会话分支中同步更新状态的 React 规则违规。
- 修复草稿快照迁移事务错误码缺少中英文界面文案映射的问题。
- 修复多处过期测试断言与缺失的 Electron mock（M05 迁移车道、蓝图清理调用次数、生成预算预留、头像 IPC 生命周期），测试基线恢复可信。

### 发布说明

- Windows x64 安装包发布渠道为 GitHub Releases；安装包未签名，Windows 可能显示未知发布者提示。
- 本版本数据库 schema 版本为 `9`，包含 `M08` 草稿快照迁移；便携档案与本地存档包含快照数据。

## English

### Added

- Draft auto snapshots: every save and every AI generation that lands a draft now records a snapshot of that chapter's draft (up to 30 per draft; identical content is never recorded twice). The version menu lists snapshots by time, word count, and source (on generation / on save).
- Restore a snapshot as a new draft: pick a snapshot from the version menu to create a new draft from it. Nothing is overwritten or deleted; merging a revision into a draft records a snapshot as well.
- Top bar save status: saving, saved (hover shows the last saved time), unsaved, and save failed are now clearly distinguished. A failed save can be retried from the top bar with one click. The status belongs to the book you are writing — switching books never shows the previous book's save state.

### Improved

- The snapshot menu explains itself when reading fails or no snapshots exist yet; restoring no longer pre-reads the next version number — new draft versions are allocated atomically inside the database transaction, so a concurrent save can no longer produce a wrong version hint.

### Fixed

- Registered schema-8 projects can now upgrade in place to schema 9: the upgrade entry accepts all registered historical versions, verifies the schema fingerprint and author data first, and migrates inside one transaction.
- Fixed a React rules violation in the version switcher where a stale project session branch updated state synchronously.
- Added the missing Chinese/English message mapping for the draft snapshot migration transaction error code.
- Fixed several stale test assertions and a missing Electron mock (the M05 migration lane, blueprint-clear call counts, generation budget reservation, avatar IPC lifecycle), restoring a trustworthy test baseline.

### Release notes

- Windows x64 installer is distributed via GitHub Releases. The installer is not code-signed; Windows may show an unknown-publisher warning.
- This release uses database schema version 9, including the M08 draft snapshot migration; portable archives and local archives include snapshot data.
