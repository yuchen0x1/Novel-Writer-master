# 1.7.1

## 中文

### 新增

- 场景卡正式落地：蓝图章节下可以按顺序创建、编辑和删除场景卡，记录地点、故事时间、人物、目标、冲突、转场与备注。
- 场景卡使用独立 SQLite 表持久化，通过新的 M07 迁移升级到 schema 版本 8；删除章节和清空蓝图时会同步清理场景卡。
- 中文作品的审稿维度新增「中文校对」，只检查客观的错别字、漏字或重字、中文标点、明确语法错误和无歧义的词语搭配错误。
- 时间线、写作目标、DOCX/PDF 导出和编辑器输入体验继续补齐，并增加对应的主进程控制器、共享契约和回归测试。

### 修复

- 小说配置解析现在只接受裸 JSON 或完整单一 JSON 围栏，拒绝解释性文字、多重 JSON 围栏和混合响应，避免把模型说明文字误当成有效配置。
- 场景卡在项目会话切换时不再短暂展示旧章节数据。
- 审稿中心从问题卡跳转时会定位到具体引用锚点，而不只是打开章节。
- 修复工作流恢复测试与瞬时失败重试策略之间的调用次数契约，并更新中文校对 Skill 的稳定内容指纹。
- 发布前类型检查、lint 和版本元数据检查已纳入本次发布验证。

### 发布说明

- Windows x64 installer release channel: GitHub Releases. The installer is not code-signed; Windows may show an unknown-publisher warning.
- Codex dual links and bidirectional timeline-to-source navigation remain planned for a later release.

## English

### Added

- Scene cards are now available inside each chapter blueprint. Authors can create, edit, reorder by explicit scene order, and delete cards containing location, story time, participants, goal, conflict, transition, and notes.
- Scene cards use a normalized SQLite table and the new M07 migration, bringing the schema to version 8. Chapter deletion and blueprint clearing remove related scene cards as well.
- Chinese projects now have a Chinese proofreading review dimension limited to objective typos, missing or duplicated characters, Chinese punctuation, clear grammar errors, and unambiguous word-collocation errors.
- Timeline, writing goals, DOCX/PDF export, and editor input behavior received additional completion work with matching main-process controllers, shared contracts, and regression tests.

### Fixed

- Novel configuration parsing now accepts only a raw JSON object or one complete JSON fence. Explanatory prose, multiple fences, and mixed responses are rejected instead of being applied.
- Scene cards no longer briefly show data from the previous project session after a session switch.
- Review-center navigation now lands on the specific quoted anchor instead of only opening the chapter.
- Workflow recovery tests now match the bounded transient-retry contract, and the built-in Chinese proofreading skill fingerprint is updated.
- Release type checks, lint checks, and version metadata checks are included in this release verification.

### Release notes

- Windows x64 installers are not code-signed and may show an unknown-publisher warning.
- Codex dual links and bidirectional timeline-to-source navigation remain planned for a later release.
