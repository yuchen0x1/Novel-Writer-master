# 1.8.0

## 中文

### 新增

- 上下文硬规则触发器（Lorebook）：写稿前自动扫描本章蓝图、作者指导与上一章结尾，命中角色别名或世界观设定关键词时，把对应角色档案与设定词条强制注入 Prompt；运行侧页会显示激活了哪些规则。向量检索漏召回导致的「吃设定」有了确定性兜底。
- 正文双向链接：输入 `[[` 弹出角色与世界观设定联想补全（含角色别名），采纳后写成 `[[名称]]`；已成文的链接按主题色高亮，鼠标悬停弹出速览卡片（角色定位、性格、能力、当前境界或设定摘要）。
- 分屏对照模式：单章正文标题行新增「对照」开关，左栏可拖拽调宽并钉住本章蓝图要点与场景卡，右侧照常沉浸写作；面板宽度持久化，开关状态跨章节记忆。
- 打字机居中滚动：标题行新增「打字机」开关，光标所在行自动保持在滚动视口中部（沉浸纸面下滚外层页面），状态持久化。
- 网文节奏雷达：审稿报告内置本地统计——对话占比与轮数、平均段落字数、超 220 字长段占比、章尾钩子判定（强/弱/无），长段过多或结尾无钩子时给出提示；全部本地计算，不调用模型。
- 状态核对：审稿报告列出本章蓝图出场、但动态状态（境界/战力、伤势、位置等）停更在更早章节的角色，提醒核对或在角色卡更新状态。

### 改进

- 模型 API Key 本地加密存储：`models.json` 中的 Key 改用系统级加密（Electron safeStorage）落盘，读取时自动解密；旧配置的明文 Key 完全兼容，下次保存自动升级为密文，系统加密不可用时平滑回退。

### 修复

- 修复补全候选会被 CodeMirror 模糊匹配整段丢弃的问题（`[[` 前缀永远匹配不上词条名），链接补全改为按名称与别名自行过滤。

### 发布说明

- Windows x64 安装包发布渠道为 GitHub Releases；安装包未签名，Windows 可能显示未知发布者提示。

## English

### Added

- Lorebook triggers: before drafting, the chapter blueprint, author guidance, and the previous chapter's ending are scanned for character aliases and world-setting keywords. Matched character profiles and setting entries are force-injected into the prompt, and the run side panel lists the activated rules. This adds a deterministic safety net when vector retrieval misses established facts.
- Inline wikilinks: typing `[[` opens entity completion for characters (including aliases) and world-setting entries; accepted links are stored as `[[Name]]`. Existing links are highlighted in the accent color and hovering shows a quick-preview card (role, personality, abilities, current power level, or the setting summary).
- Split reference view: a new "Split" toggle in the chapter title bar pins this chapter's blueprint highlights and scene cards in a resizable left panel while the prose stays immersive on the right. Panel widths persist and the toggle is remembered across chapters.
- Typewriter scrolling: a "Typewriter" toggle keeps the caret line near the vertical middle of the scroll viewport (scrolling the outer page in fit-content mode). The preference persists.
- Pacing radar: the review report now includes local-only metrics — dialogue share and turns, average paragraph length, the share of paragraphs over 220 characters, and an ending-hook verdict (strong/weak/none) with hints when paragraphs run long or the ending lacks a hook. No model calls involved.
- State check: the review report lists blueprint cast members whose dynamic states (power level, injuries, location, and so on) were last author-confirmed in earlier chapters, prompting a check or a character-card update before writing.

### Improved

- Model API keys are now encrypted at rest: keys in `models.json` are sealed with OS-level encryption (Electron safeStorage) and decrypted on load. Existing plaintext keys keep working and are upgraded automatically on the next save; a graceful fallback applies when system encryption is unavailable.

### Fixed

- Completion candidates are no longer discarded by CodeMirror's fuzzy matcher (the `[[` prefix never matched entry names); link completion now filters by name and alias itself.

### Release notes

- Windows x64 installer is distributed via GitHub Releases. The installer is not code-signed; Windows may show an unknown-publisher warning.
