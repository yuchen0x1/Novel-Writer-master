# Security policy

Report vulnerabilities privately through [GitHub Security Advisories](https://github.com/yuchen0x1/Novel-Writer-master/security/advisories/new). Include the application version, operating system, affected feature, and the smallest safe reproduction. Redact model credentials, GitHub tokens, and unpublished manuscripts. Use public issues for ordinary bugs and compatibility reports.

Security fixes target the latest stable version of the desktop app. See [update and signing status](docs/AUTO_UPDATE.md) and use the [official release assets](https://github.com/yuchen0x1/Novel-Writer-master/releases).

# 安全问题

请通过 GitHub 的私密安全报告提交受影响的版本、操作系统、入口与最小复现。提交前删除凭据、私人文件路径和未发表的正文。普通故障和兼容性问题可以走公开 Issue。
