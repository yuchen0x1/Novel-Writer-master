## 差距与本轮吸收

| 维度 | 本项目现状 | 参照证据 | 本轮决策 |
| --- | --- | --- | --- |
| 长篇事实源 | 作者确认角色、蓝图与定稿，保持派生视图可重建 | Pagekin、NovelForge、Inkwell | 保留事实和派生隔离，下一轮优先提高估算和来源可读性。 |
| 人工修订 | 已有审稿确认、差异比较和版本历史 | Inkwell、ZenStory、Scrivener | 保留确认式工作流。候选按改动定位、撤销和归档设置验收。 |
| 独立平台 | Windows 和双架构 macOS。同一写作模型，独立安装与权限 | Joplin、StoryForge、NEO | 维护原生文件和凭据边界，暂缓额外发行目标。 |
| 早期预检 | 已有许可证、依赖覆盖和发布验证，CI 常态失败 | electron-builder、Zettlr | 优先修复 CI，实现新标签的三平台草稿与公开校验。 |
| 更新入口 | Windows 在应用中下载，macOS 打开官方发行页 | Zettlr 与 electron-builder | 提醒按平台说明实际动作，macOS 拒绝草稿和预发布元数据。 |
| 专注交互 | 多阶段、正文和运行侧页各有入口 | novelWriter、FocusWriter、NEO | 保持现有布局，后续从快捷定位、低干扰反馈和紧凑窗口入手。 |
| 交换与可移植 | 本地项目和导出，历史备份可独立恢复 | novelWriter、novelibre、Joplin | 先验证导出和恢复，跨设备编辑依赖独立的并发和同步设计。 |

商业参照补充采用 [Scrivener](https://www.literatureandlatte.com/scrivener/overview) 的分段写作、快照、集中导出和单独的 iOS 产品形态。GitLab 分布的 [KDE Ghostwriter](https://invent.kde.org/office/ghostwriter) 与 Gitee 的 [51mazi](https://gitee.com/xsxjlzy/51mazi/blob/main/README.md) 分别补充专注编辑和中文桌面创作参考。社区索引用于发现对象，功能判断优先取官方说明、代码目录和记录。

近期值得关注的变化包括 Ollama 的请求前缀复用、LanceDB 的语义采样文档、Zettlr 的更新对话框上下文以及 oh-story-claudecode 的越视角检测。上表链接指向调研时的最近提交。单条 Issue 用于定位维护方向，高频需求仍需盘点重复报告和实际复现。
