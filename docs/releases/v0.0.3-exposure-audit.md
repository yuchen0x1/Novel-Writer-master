## 客户端无法解决的问题

本次扫描未发现可确认的长期服务端凭据，亦未识别本产品自有的付费授权最终判定；这不等于证明不存在。用户自行配置的模型 API Key 必须在调用模型服务时使用，不能靠客户端混淆保证对设备所有者保密。系统凭据库与主进程边界只降低意外暴露风险。若未来引入订阅、计费或长期服务凭据，应由服务端做最终校验，客户端只持有必要的短期凭据。

更新资产的 SHA-256/SHA-512 与 GitHub digest 可验证字节一致性，不能替代发行者签名，尤其不能防御官方仓库或发布权限失陷。本次签名边界在中英文发布说明中保留明确披露。
