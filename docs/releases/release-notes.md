# 更新说明

## 2.0.0 — 2026-11-27

- 修复项目配置部分更新时清空其他设置、单文件导入遗漏前言、定稿稿件并发覆盖、WebDAV 下载短写、云备份切换作品后的误报，以及归档稿干扰写作统计和检索的问题。
- 修复提示词编辑输入丢失、同路径重开作品复用旧草稿读取、模型连接测试卡住，以及更新失败隐藏、更新状态竞争和自动检查节流绕过等问题。
- 加固 PDF 导出隔离会话、MCP 工具错误和断线生命周期、Windows 安全文件 helper 的 UTF-8 与管道错误处理；保存其他模型时保留无法解密的既有 API Key 密文。
- 硬件加速偏好现在从经过验证的全局配置读取，并在 Electron ready 前生效。
- 本次使用 `2.0.0` 作为版本序列桥接，高于旧 `1.x` 和中间 `0.0.x` 系列。通过官方更新源安装的旧版可发现更新提示；作品数据目录和 appId 保持不变。

## 0.0.3 — 2026-11-19

- 修复作品恢复路径预检、预约标记创建失败时的残留、云备份登录 profile 绑定与角色名单解析静默截断等问题；中断恢复保留受控预约供重试。
- 后处理守卫现在区分状态缺失与读取错误；改进 Windows 路径预检、WebDAV 响应验证与草稿快照事务一致性。迁移进程被强制终止后，临时数据库快照仍可能残留。
- 此版本为稳定性维护，界面语言、作品正文与写作语言设置行为不变。

## 0.0.2 — 2026-11-19

- 应用启动时按系统语言自动选择中文或 English，设置页可手动切换并保存。
- 窗口壳层、设置和关于入口即时更新；作品正文、提示词和写作语言设置保持原样。
- macOS 更新弹窗会指引用户打开官方下载页并选择与设备架构对应的安装包。
- 助手聊天入口保持隐藏（README 常见问题既有说明），写作、审稿、修稿流程不受影响。

## 0.0.1 — 2026-11-13

- 应用启动页、窗口、关于页、安装显示名与项目主页统一使用 `Novel-Writer-master`。
- 关于页不再显示旧产品名；中英文界面图和主页宣传图从当前应用重新拍摄。
- 下载、更新发布与问题讨论入口统一指向 `yuchen0x1/Novel-Writer-master`。
- 已有作品、设置和安装识别继续兼容；此次名称修正不会迁移或清空用户数据。

版本序列从 0.0.1 重新开始。旧 1.x 客户端需要手动安装一次；后续按新版本序列更新。Windows 安装包未签名；macOS 使用 ad-hoc 签名，未公证。详情见 [0.0.1 发布说明](../../.release/notes/v0.0.1.md)，实际可下载资产以 [GitHub Releases](https://github.com/yuchen0x1/Novel-Writer-master/releases) 为准。
