## 签名与实际验收边界

- Windows 安装包为 **unsigned**，Authenticode 状态 `NotSigned`；没有发行者证书身份保证，SmartScreen 或企业策略可能提示或阻止。
- macOS 两架构为 **ad-hoc** 签名，没有 Developer ID、公证；`codesign --verify --deep --strict` 通过不代表 Gatekeeper 无提示放行。
- 覆盖升级与手动回退使用同一隔离 canonical generation 和 Chromium profile，检查合成作者文件及选定全局配置。它不证明完整 SQLite 项目降级，也不是自动二进制回滚。
- 原生更新演练使用真实公开旧版与新版及真实 UI 操作；其数据范围为回执列明的合成 fixture，不代表所有真实用户数据组合。
- 草稿快照写入与裁剪采用同一事务；强杀或断电仍可能留下迁移临时数据库快照，没有自动回收保证。
- 恢复流程清理预约标记创建失败时的自有空预约与日志；已经建立的受控中断预约保留供重试，不声称任意中断都自动删除恢复目录。
- 逆向暴露面与扫描覆盖限制见 [v0.0.3 审计](v0.0.3-exposure-audit.md)。启发式静态扫描不等同于最终包完整安全证明。
