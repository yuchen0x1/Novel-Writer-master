# v0.0.3 发布核验

记录日期：2026-11-19（Asia/Shanghai）。本页区分本地检查、云端安装包资格与正式公开资产；未完成的检查不作为通过证据。

## 当前状态

v0.0.3 正在准备发布，尚未记为正式公开。三平台资格构建、草稿资产核验、正式发布与公开下载复核的实际运行链接将在完成后补齐。

## 本地验证

- 版本升级后的全量测试：468 个文件，6,564 passed、13 skipped、5 todo。
- 类型检查、ESLint、色彩字面量、翻译覆盖率与发布文档一致性检查通过。
- 首次 Windows CI 在两处成功路径测试中因夹具目录过深而失败。仅缩短两个测试目标目录，生产路径预检保持不变；相关 74 项测试通过。云端重跑结果以实际运行记录为准。

## 已知边界

- Windows 安装包未做 Authenticode 签名；macOS 为 ad-hoc 签名且未公证。
- 强制终止或断电后，迁移临时数据库快照仍可能残留；未宣称已加入自动清理。
- 全新安装资格不能替代旧版本应用内升级及数据保留验收。应用内更新验收应明确记录源版本与目标版本。
- 分支按维护者选择清理为仅保留 main；11 个依赖升级分支未合并，治理分支的六个文件已独立提交到 main。
